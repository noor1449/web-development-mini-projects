# Image Search Engine
A simple, beautiful, and interactive single-page web application that lets you search for images based on keywords. The project uses HTML5, CSS3 (Grid layout), and Vanilla JavaScript to dynamically fetch and display pictures from an open-source image network—**no registration or API access keys required!
## 🌐 Live Demo
You can view and test the live project running directly in your browser here:

# Features
1. Keyword-Based Search: Instantly look up images matching any word or phrase (e.g., "nature", "space", "architecture").
2. Infinite Pagination: Click the **"Show more"** button to dynamically load the next batch of images without refreshing the page.
3. Responsive Layout: Powered by CSS Grid to show a neat 3-column photo wall layout.
4. Interactive Links: Clicking any image opens up a high-resolution version of that image in a new browser tab.
5. Zero Configuration: Works right out of the box. No need to register for an Unsplash, Pexels, or Pixabay developer account.
