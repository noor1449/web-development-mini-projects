# Simple To-Do List Web App
A clean, responsive, and interactive To-Do List application built using vanilla HTML, CSS, and JavaScript. This app allows users to efficiently manage daily tasks with a beautiful, gradient-themed user interface.
## Features
1. Add Tasks: Quickly type in a task and add it to your daily list.
2. Input Validation: Prevents empty tasks from being added by alerting the user.
3. Toggle Completion: Click on any task to mark it as completed with a strike-through text effect.
4. Delete Tasks: Easily remove individual tasks from the list by clicking the close (`×`) icon.
5. Persistent Data (Local Storage): Your tasks are automatically saved to your browser's Local Storage, meaning your list remains intact even if you refresh or close the page.
## Tech Stack
1. Frontend: HTML5
2. Styling: SS3 (featuring a Poppins custom font and a modern linear gradient layout)
3. Scripting: Vanilla JavaScript
4. Storage: Web Storage API (`localStorage`)
