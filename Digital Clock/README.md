# Digital Clock

A sleek, minimalist, and real-time digital clock web application. Built purely with semantic HTML5, CSS3 for layout presentation, and native JavaScript to dynamically track and render time exactly down to the second.

---

## 🌐 Live Demo

You can view and test the live digital clock running directly in your browser here:
[https://noor1449.github.io/projectname/index.html]
## Features
- Real-Time Tracking: Uses JavaScript asynchronous timing intervals to keep the clock precisely synchronized with your device's local system time.
- Zero-Padding Formatting: Dynamically checks time digits and automatically prefixes a leading `"0"` whenever hours, minutes, or seconds drop below single digits (e.g., displaying `05` instead of `5`).
- Clean UI Presentation: Centered layouts using clean, proportional typography styling separation.
