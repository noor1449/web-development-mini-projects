# ⏳ Circular Progress Bar with Animated Counter
A stylish, animated **Circular Progress Bar** component built using modern **HTML5**, **SVG elements (with Linear Gradients)**, **CSS3**, and **Vanilla JavaScript**. The progress indicator smoothly counts up from 0% to 65% upon page load with a vibrant gradient look.
## Live Demo
You can interact with and test this animated component directly in your web browser:
https://noor1449.github.io/web-development-mini-projects/Circular-Progress-Bar/index.html
## Features
1. Vibrant Vector Graphics:** Uses a native SVG `<circle>` styled with a custom `<LinearGradient>` matching a beautiful Deep Pink (`#e91e63`) to Purple (`#673ab7`) color transition.
2. Smart Animation Counter:** Backed by an optimized JavaScript dynamic interval loop (`setInterval`) that cleanly increments the numeric value layout smoothly every 30 milliseconds.
3. Neat Layering Structure:** Concentric layout circles (`.outer` and `.inner`) designed to align perfectly behind the SVG stroke line track.
