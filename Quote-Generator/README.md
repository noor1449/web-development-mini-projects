# Quote Generator
A clean, responsive, and dynamic web application that fetches random inspirational quotes from an API and allows users to tweet their favorites instantly. Built with semantic HTML5, CSS3, and asynchronous Vanilla JavaScript.
## Live Demo
You can view and test the live project running directly in your browser here:
[https://noor1449.github.io/projectname/index.html]
## Features
- **Dynamic API Fetching:** Connects to the public `dummyjson.com` API to retrieve random quotes and their authors asynchronously on page load or button click.
- **Instant Twitter Sharing:** Features a "Tweet" button that automatically creates an optimized Twitter intent link, opening a pop-up window formatted with the quote and author text ready to share.
- **Robust Error Handling:** Includes `try...catch` network verification blocks to cleanly display a user-friendly fallback message if the quote fails to load.
